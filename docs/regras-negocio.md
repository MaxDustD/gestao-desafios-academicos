# Regras

- Programa deve possuir coordenador.
- Programa deve possuir professor responsável.
- Programa deve possuir ambiente institucional.
- Professor colaborador é opcional.
- Professor colaborador não pode ser igual ao responsável.
- Programa precisa ter ao menos um desafio.
- Programa precisa ter ao menos uma fase obrigatória.
- Fases obrigatórias precisam de avaliação.
- Não pode haver duplicidade.
- Não pode alterar programa finalizado.
